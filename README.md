# 한판 HANPAN

브라우저에서 바로 하는 오리지널 HTML5 게임 모음. 맨 위 `index.html`이 첫 화면이에요.

| 폴더 | 게임 |
|---|---|
| `roadkorea/` | 로드 코리아 — 실제 지도 3D 운전 |
| `corebreaker/` | 코어 브레이커 — 5대5 전술 슈팅 |
| `poparena/` | 팝 아레나 — 3대3 탑뷰 난투 |
| `cubeland/` | 큐브랜드 — 블록 샌드박스 |
| `lastisland/` | 라스트 아일랜드 — 배틀로얄 |
| `duelstrike/` | 듀얼 스트라이크 — 1대1 대전 격투 |
| `hanpanmini/` | 한판 미니 — 가벼운 게임 5종 |
| `turbocircuit/` | 터보 서킷 — 3D 카트 레이싱 (신작) |

## 내 컴퓨터에서 실행

자바스크립트 모듈을 써서 웹 서버가 필요해요.

```bash
python -m http.server 8000
```

그다음 http://localhost:8000 을 여세요. 자세한 내용은 `README.txt`를 보세요.
